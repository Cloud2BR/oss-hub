delivery. Viewers can learn a concept, experiment with it, build a useful
solution, and find the implementation in GitHub.

## Keep each format distinct

| Format | Viewer question | Example |
| --- | --- | --- |
| **Labs** | What happens when we experiment with this technology? | Explore Azure AI Search and observe how it works. |
| **MVPs** | How can we turn this capability into something useful? | Build a working RAG application with Azure AI Search. |
| **Certifications** | What do I need to know and practice for the exam? | Prepare for AI-102 with concepts, study guidance, and labs. |

Labs are intentionally exploratory. MVPs have a defined outcome and demonstrate
the path from concept to implementation. Certification episodes focus on exam
objectives and repeatable preparation.

## Episode blueprint

Each technical episode should follow a predictable structure:

1. **Context** — state the audience, problem, and expected outcome.
2. **Concept** — explain only the technology needed for this episode.
3. **Walkthrough** — demonstrate the steps in a real environment.
4. **Validation** — test the result and discuss trade-offs, limits, and cost.
5. **Next step** — link the related series, GitHub assets, and follow-up episode.

## Content planning model

| Stage | Content objective | Typical output |
| --- | --- | --- |
| **Foundation** | Establish the language and core concepts. | TEC Hub lesson or English/Español explainer |
| **Orientation** | Show the Microsoft Cloud services and available options. | Microsoft Learning Hub demo |
| **Experimentation** | Test one capability with a focused hypothesis. | Lab or sandbox walkthrough |
| **Implementation** | Combine components into a useful, small solution. | MVP build and demonstration |
| **Validation** | Reinforce skills against a professional objective. | Certification study episode |
| **Reference** | Make the work reproducible and easy to continue. | GitHub repository, notes, and next episode |

This model lets one topic become a connected playlist rather than a collection
of unrelated videos. For example, RAG fundamentals can lead to an Azure AI
services exploration, an Azure AI Search lab, a working RAG MVP, and AI-102
certification practice.

## Publishing checklist

- Define the series, language, audience level, and learning outcome.
- Link the episode to a previous concept and a useful next step.
- Keep demos reproducible with a repository, prerequisites, and cleanup steps.
- Show validation results, limitations, and any cost or security considerations.
- Add chapters, captions, a concise description, and links to the relevant
  Cloud2BR organization.
